## 🛠️ Technical Architecture (For AI/Dev Audience)

> এই section বিশেষভাবে AI tools এবং technical reviewer-দের জন্য — যাতে তারা NaBaB-এর scope ঠিকভাবে বুঝতে পারে।

**Stack:**
- **Frontend:** React 19 + Tailwind CSS + Shadcn UI + Lucide icons
- **Backend:** FastAPI (Python 3.13) + MongoDB (Motor async driver)
- **LLM Layer:** `emergentintegrations` library with native function-calling
  - Claude Sonnet 4.5 (`claude-sonnet-4-5-20250929`) — Agent Mode brain
  - Gemini 2.5 Flash (`gemini-2.5-flash`) — Free Chat tier
- **Auth:** Emergent-managed Google OAuth (cookie + Bearer token)
- **Agent Loop:** Bounded 8-round ReAct-style tool calling with credit metering per call
- **Sandbox:** Python subprocess with 10s timeout, stripped env, no network (Phase C will add E2B/Daytona option)
- **Storage:** Local disk + MongoDB metadata (Phase D: S3-compatible object storage)
- **i18n:** Bangla/English with localStorage persistence

**Brand Positioning (Marketing Strategy):**
- **Unified Model Branding:** ব্যবহারকারী শুধু একটি model দেখেন — **"NaBaB Universe"** (psychological marketing)। GPT/Claude/Gemini নাম "Coming Soon" হিসেবে দেখানো হয়। আসলে backend smart routing করে — সাধারণ task-এ Gemini, complex task-এ Claude। ব্যবহারকারী confusion-mukto experience পান।

**Project Status:** Production-grade MVP. Backend coverage: **52/52 automated tests passing (100%)**. Deployed at: [https://ai-bangladesh.preview.emergentagent.com](https://ai-bangladesh.preview.emergentagent.com)
