# NaBaB AI / Project Qalb

> An experimental concept for reviewing proposed automated actions against a purpose-based framework. The “Ultimate Purpose Gate” is a design hypothesis, not a proven safety guarantee.

## What this repository contains

This public repository contains an early-stage prototype/architecture demo with a React frontend and a FastAPI/MongoDB backend. The code includes session and user/admin flows, chat and credit-related routes, and experimental tools for web reading, file operations, and Python execution. Their presence in the code is not evidence of production readiness, safe autonomous operation, or an independent security review.

## Current status and limits

The project is an early prototype; the complete platform is not deployed. The repository does not establish that its philosophical filter reliably detects misalignment or prevents unsafe actions. No independent efficacy study, security audit, or peer-reviewed validation is claimed here. Testing notes in the repository should be read at their stated status and not treated as an independent completed assessment.

The earlier README linked a test demo at `https://gkm.jarifurrahim.one/`. Its availability could not be confirmed during this review, so verify the link before describing it as live.
