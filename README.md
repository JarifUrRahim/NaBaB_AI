# Project Qalb: The Existential Gatekeeper (NaBaB AI)

> **"A singular philosophical filter agent that halts misalignment by evaluating automated actions against the core purpose of human life."**

## 🚀 The Vision: Beyond Micro-Rules
Current agentic systems rely on endless micro-rules (e.g., "don't spend over $100", "don't email strangers") to prevent catastrophic loops. But AI lacks common sense and always finds a logical gap. 

**Project Qalb (NaBaB AI)** introduces a completely different architecture: **The Ultimate Purpose Gate**. Instead of complex code-based restrictions, this architecture uses a single, highly specialized filter agent trained solely on the ontological purpose of human life. Before any sub-agent executes a final action (spending money, delegating access, deploying code), it must pass through this binary philosophical filter. If an action contradicts fundamental human purpose or ethical reasoning, it is instantly halted and queued for human validation.

## 🔄 Dual-Track Training & Deployment
To manage high hosting costs and compute limits, I am currently employing a dual-track development method:
1. **Local Mobile Sandbox:** One version of the model is built as an application format installed directly on my mobile device, where I am actively training the agent's behavioral patterns and edge cases locally without incurring heavy server costs.
2. **The Cloud Platform (This Repo):** The main web-based infrastructure intended for the final, scalable platform.
